# STELLA Vault — Landing & Download Site

The public marketing site for **STELLA Vault**, a digital paluwagan (rotating
savings circle) built on Stellar. This site's only job is to explain the
product and get people to download the app — there's no sign-in, dashboard,
or backend here.

## Tech stack

| Tool | Why |
|---|---|
| [Astro](https://astro.build) | Static-first — ships ~0 JS by default, ideal for a marketing page |
| [React](https://react.dev) | Only hydrated where needed (FAQ accordion, hero animation) as islands |
| [Tailwind CSS](https://tailwindcss.com) | Utility styling, brand tokens centralized in `tailwind.config.mjs` |
| [anime.js](https://animejs.com) | Ambient hero background motion |
| [Motion](https://motion.dev) | FAQ accordion open/close animation |
